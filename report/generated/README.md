# report/generated

Files written by `report/make_tables.py`; do not edit by hand.

| File | Content |
|------|---------|
| `tab_<name>.tex` | One LaTeX table per file, generated from the CSV named in its caption. |
| `numbers.tex` | `\newcommand` macros for the numbers quoted in the prose of `main.tex`. |
| `generator_defaults.csv` | Default parameters of `synthetic.scenario.ScenarioConfig`, written from the code so that the generator comparison table reads from a CSV. |
| `commits.tex` | Commit list of the working branch for the reproducibility appendix. |
| `crosscheck.txt` | Values quoted in the READMEs compared with the CSV files. |
