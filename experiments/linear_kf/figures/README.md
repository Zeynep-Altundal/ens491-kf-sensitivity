# experiments/linear_kf/figures

PNG figures written by `plots.py`:

| File | Content |
|------|---------|
| `rmse_vs_s.png` | RMSE versus scale factor for the Q, R and P0 sweeps. |
| `nees_nis_vs_s.png` | Mean NEES and NIS versus scale factor with expected values. |
| `example_trajectory_q_sweep.png` | Example trajectory for the Q sweep at s = 0.001, 1, 1000. |
| `gain_convergence.png` | Kalman gain entries and their relative deviation from steady state versus step. |
| `grid_heatmaps_T200_full.png` | RMSE and NEES over the Q-R grid, `T = 200`, all steps. |
| `grid_heatmaps_T2000_steady.png` | RMSE and NEES over the Q-R grid, `T = 2000`, steps `k >= 1000`. |
